# ProBeauty — сайт салона красоты в Киеве

Концепт-проект для портфолио: бренд и данные вымышлены, заявки не обрабатываются (`DEMO = true`).

- Сайт: https://probeauty.pages.dev/
- Одна HTML-страница (`index.html`) с переключением страниц по `#хэшу`, языки RU/EN
- Шрифты: Tenor Sans (заголовки), Inter Tight (текст)
- Хостинг: Cloudflare Pages, автодеплой из ветки `main`

Дизайн и разработка: Spatters Digital.
